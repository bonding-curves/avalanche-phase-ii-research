Sterman | 1984 | Sterman splits a model's mean square error into bias, unequal variation, and unequal covariation, so a fit report shows whether the error is systematic or noise. |
| [Formal aspects of model validity and validation in system dynamics](/Phase-II/Wiki/Collections/Supplementary-Research-Papers/1996-Model-Validity-in-System-Dynamics) | Yaman Barlas | 1996 | Barlas sets out the order in which a system dynamics model should be tested, structure first, then behavior tests that expose structural flaws, then the match to historical patterns. |
