The agreement's milestones, one folder per deliverable. The [Phase II overview](/Phase-II/) lists every deliverable's status on one page.

- [Milestone 1](/Phase-II/Milestones/Milestone-1/): data ingestion, model definition, and behavioural calibration
- [Milestone 2](/Phase-II/Milestones/Milestone-2/): parameter sweeps, simulation, and sensitivity analysis
- [Milestone 3](/Phase-II/Milestones/Milestone-3/): recommendations, playbook, open-source release, and knowledge transfer
