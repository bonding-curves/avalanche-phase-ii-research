Milestone 2 success criterion:

> Sensitivity Analysis Report delivered covering all key parameters

## Status

Not started as of 2026-09-28.

## Result

When delivered, this page will show a table of every KPI with its definition and success threshold, then explain how each trajectory's KPI values are computed and scored as pass or fail. The proposal names seven KPIs: staking ratio, validator count, decentralization, net inflation, validator profitability, APR volatility, and staking volatility. Across 50,000 trajectories that is about 350,000 KPI values.
