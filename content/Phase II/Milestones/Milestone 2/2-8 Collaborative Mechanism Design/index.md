## Contract requirement

> Support for evaluating alternative reward mechanisms proposed by Avalanche or external teams

Milestone 2 success criterion:

> Sensitivity Analysis Report delivered covering all key parameters

Quoted from the [Signed Grant Agreement](/Phase-II/Milestones/Milestone-0/Signed-Grant-Agreement).

## Status

Not started as of 2026-09-28.

## Result

When delivered, this page will show a table that compares each proposed reward mechanism with the current reward function on the same scenarios and KPIs, then explain the interface for adding a mechanism. The agreement's detail for this deliverable sets three terms: an interface that swaps the duration-dependent reward function for another form without restructuring the simulation, an evaluation within 5 business days per proposal, and output as correlation tables, confidence ratings, and recommendation tiers. Its examples of mechanisms are node-age weighting, activity multipliers, and alternative duration curves.
